# A4P Java SDK 版本记录 / Release Notes

## 0.3.0

A4P Java SDK 首个公开发布版本，提供 A4P 支付意图协议的 Java 17 实现。

- 支持支付意图处理、购物车匹配以及状态和额度记账。
- 提供签名与验签回调，以及 Context 的 JSON 序列化和反序列化接口。
- Maven 坐标为 `io.openjiuwen:a4p-java-sdk:0.3.0`。从源码构建需要 JDK 17+ 和 Maven 3.9+。

First public release of the A4P Java SDK, a Java 17 implementation of the A4P payment intent protocol.

- Supports payment intent processing, shopping cart matching, and state and limit accounting.
- Provides signing and verification callbacks and JSON serialization and deserialization for Context.
- Maven coordinates are `io.openjiuwen:a4p-java-sdk:0.3.0`. Building from source requires JDK 17+ and Maven 3.9+.
