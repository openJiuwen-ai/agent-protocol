# @openjiuwen/iiap

TypeScript SDK for the Implicit Intent Aware Protocol (IIAP).
It turns privacy-safe UI interaction events into intent context packets and
supports optional, non-blocking assistance.

The package exposes the runtime from `@openjiuwen/iiap` and supported modules
through subpath imports such as `@openjiuwen/iiap/a2ui-v08`,
`@openjiuwen/iiap/http`, and `@openjiuwen/iiap/react`.

This `0.1.0-rc.1` artifact is a source release candidate. It is not yet published
to the public npm registry. Build and installation instructions are in the
[IIAP SDK documentation](../../../../docs/en/README.md).
